# Requirements Archive: VARIANT v1.0

**Archived:** 2026-03-20
**Milestone:** `v1.0`
**Status:** 21 / 21 satisfied

## v1 Requirements

### Experience

- [x] **EXP-01**: Visitor can navigate homepage, catalog, category pages, and product pages without broken layout, dead-end UI, or misleading interaction patterns
- [x] **EXP-02**: Visitor gets a coherent and trustworthy visual experience across desktop and mobile entry points
- [x] **EXP-03**: Visitor can complete the main browsing journey from homepage to category to product detail without UX friction that blocks evaluation
- [x] **EXP-04**: Visitor can use launch-critical CTAs and navigation elements without placeholder or non-functional links

### Lead Generation

- [x] **LEAD-01**: Visitor can submit lead intent from homepage and product contexts through a working CTA flow
- [x] **LEAD-02**: Lead payload sent by webhook includes the fields needed to create opportunities in `ibl-ai-os`
- [x] **LEAD-03**: Lead submission failures are detectable through clear frontend handling or operational logging paths
- [x] **LEAD-04**: Lead capture behavior is consistent across desktop and mobile variants

### Content And SEO

- [x] **SEO-01**: Category and product pages expose accurate metadata, canonical information, and structured data in a production-safe way
- [x] **SEO-02**: Product content, labels, and machine-specific information remain internally consistent across generated pages
- [x] **SEO-03**: Visitor can trust that page content matches the machine being viewed, without obvious copy drift or stale artifacts
- [x] **SEO-04**: Launch-critical pages have stable indexable output that does not depend on fragile client-side metadata injection

### Frontend Reliability

- [x] **FE-01**: Shared frontend behavior works predictably across homepage, category pages, product pages, and mobile entry points
- [x] **FE-02**: Critical browser-side logic avoids obvious runtime errors, selector fragility, and dead code that obscures the real production paths
- [x] **FE-03**: Assets required for launch render correctly without broken references or stale generated leftovers

### Generation Pipeline

- [x] **GEN-01**: Static generation flow produces reproducible catalog and product pages from source content and assets
- [x] **GEN-02**: Content and asset generation steps are documented well enough to regenerate production output safely
- [x] **GEN-03**: Generation process does not silently preserve stale files that can leak outdated content into production

### Quality And Operations

- [x] **OPS-01**: Project has a practical launch-readiness checklist covering build, smoke test, mobile check, and lead-flow verification
- [x] **OPS-02**: Production-critical behaviors can be validated before future milestones continue
- [x] **OPS-03**: Known technical debt that would block safe continuation is identified and reduced to an acceptable level
