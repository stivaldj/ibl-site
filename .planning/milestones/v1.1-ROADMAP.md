## Snapshot

This milestone tightened the homepage hero without redesigning it. The work replaced improvised positioning with a model-aware stage contract, tuned the perceived balance of all eight showcased machines, and hardened responsive and runtime behavior so the first fold remains visually stable during load and category switching.

## Phases

### Phase 7: Hero Stage Foundation

**Goal:** Establish a model-aware hero stage with explicit layout metadata, a consolidated update path, and separated right-side layers.

**Plans:**
- `07-01` Model-aware hero runtime contract
- `07-02` Hero stage wrappers and neutral CSS baseline

**Outcome:** The hero now has explicit per-model stage metadata, one consolidated runtime update path, and wrapper-based stage layers for ring, machine, and overlays.

### Phase 8: Visual Balance

**Goal:** Normalize the active machine's perceived scale and eliminate overlay competition while keeping the ring centered on the active asset.

**Plans:**
- `08-01` Per-model balance and ring tracking
- `08-02` Overlay hierarchy and responsive guardrails

**Outcome:** All eight hero models now use tuned stage values for machine mass, ring tracking, and overlay placement, with deterministic overlay ordering and bounded guardrails.

### Phase 9: Responsive Stability

**Goal:** Verify the updated hero remains intact across target breakpoints and interaction sequences.

**Plans:**
- `09-01` Breakpoint containment and mobile guardrails
- `09-02` Initial-load and rapid-switch stability

**Outcome:** The hero shell now stays bounded across desktop through mobile, and the initial render plus rapid category switching no longer reintroduce flicker, stale timers, or broken active-state visuals.

## What Shipped

- A per-model hero stage system for machine, ring, badge, title, and overlay positioning.
- Layered hero markup that separates stage elements into ring, machine, and overlay anchors.
- Tuned visual balance across the eight showcased models using shell-scoped CSS variables.
- Overlay positioning that avoids title, tech card, and model-meta competition.
- Clamp-based shell containment and mobile guardrails for the first fold.
- A deterministic hero-ready gate and revision-guarded image swaps for stable runtime transitions.
